# ortus-brand

Ortus logo and brand files.

## What is here

- Logo files: `ortus-mark.svg` (on dark), `ortus-mark-on-light.svg`, `ortus-mark-mono.svg` (takes the text colour), `ortus-avatar.svg` / `.png` (512 px, for profile pictures), `ortus-logo-dark.png` and `ortus-logo-light.png` (mark and wordmark), `ortus-social-preview.png` (1280 x 640).
- `design/`: every screen of the design, the user stories and the density rules. See `design/README.md`.

The wordmark is set in Unbounded Bold with tracking of minus 4 percent.

Part of Ortus, a sovereign workspace for organisations and governments: mail, calendar, files, documents, chat, calls, tasks and approvals that an organisation runs itself.

Status: early development, not ready for use.
